= Creare policy di backup
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
Seguire le istruzioni fornite di seguito per creare criteri di backup

. Nel riquadro di navigazione sinistro del plug-in SCV, seleziona *Criteri*, quindi seleziona *Nuova politica*.
. Nella pagina *Nuova policy di backup*, immettere le informazioni di configurazione della policy, quindi selezionare *Aggiungi*.
