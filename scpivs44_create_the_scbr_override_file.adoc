= Creare il file di configurazione scbr.override
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ./media/


[role="lead"]
IL `scbr.override` Il file di configurazione viene utilizzato dal SnapCenter Plug-in for VMware vSphere negli ambienti che supportano le operazioni di protezione dei dati basate sulle applicazioni SnapCenter .

. Vai a `/opt/netapp/scvservice/standalone_aegis/etc/scbr/scbr.override-template` .
. Copia il `scbr.override-template` file in un nuovo file chiamato `scbr.override` nel `\opt\netapp\scvservice\standalone_aegis\etc\scbr` elenco.
